# Scientific method and protocol

The authoritative machine-readable protocol is `configs/benchmark_frozen.yaml`, verified by a canonical JSON SHA-256 and source/data/dependency hashes. Primary seeds 0–29; initialization 12 outcome-blind composition groups; 15 additional selections; four policies; one CPU numerical thread. The source includes explicit warnings/fallbacks and structured decision provenance.

Primary outcome: trapezoidal AUC at steps 0–15 of best confirmed feasible mean hardness, with zero GPa before the first rank >=3 composition group. Initialization is shared per seed; its step-zero incumbent contributes to AUC. Rank threshold is operational screening, not tensile strain. No solidus constraint or physics descriptor is used. Each of two triplicate groups is reduced to mean hardness and minimum rank, with raw rows retained; no replicate splitting.

Hardness model: observed-only StandardScaler; observed-only target center and scale (floor 0.5 GPa); constant-amplitude Matérn-5/2; signal bounds [0.1,10], length bounds [0.3,6]; initial amplitude 1, length 2; deterministic L-BFGS-B max 60 iterations. GPa noise SD 0.15 is assumed, not estimated from hidden outcomes or selected for benchmark performance. Training noise `alpha=(0.15/y_scale)^2`; GP predictions yield latent SD for EI. Observation SD adds 0.15² for predictive intervals and NLL. Gaussian intervals are approximate.

Feasibility: Matérn-5/2 GPC Laplace approximation, unit amplitude, fixed length 2, max 100 predictive iterations. No rebalancing; report observed class support. For one class, use observed Beta(1,1) smoothed prior and log fallback. Probabilities clipped only numerically to [1e-7,1-1e-7].

Calibration: three-fold StratifiedGroupKFold on currently observed unique composition groups only. Each fold refits scaling/model on its training observations. Min observed n=20 and five of each class. Fit T in [1/3,3] minimizing out-of-fold mean log loss + 0.05·log(T)², no intercept. Otherwise return identity and a reason. Dataset-level min support 15 per class is drawn from the original plan before sequential replay. With seven feasible groups, real-data calibration is disabled everywhere; its implementation is exercised in correctness tests, not validated as an experimental improvement.

Policies: uniform seeded random; hardness-only latent EI with best observed hardness; CBO with EI·p_raw relative to best feasible observed hardness; RC-CBO with EI·p_cal. Product acquisition is an approximate factorization and can be misspecified if hardness/feasibility remain conditionally dependent. All remaining compositions are scored. Ties resolve in stable alloy-ID order. No-feasible mode uses p + 0.05·min(distance/sqrt(2),1), where distance is nearest observed raw-fraction Euclidean distance. This is a geometry exploration heuristic, not a physical risk bound. Support flag distance >0.35 is similarly heuristic.

Policy interface receives tuple[Observation] and tuple[Candidate], never an oracle or hidden outcome table. The engine owns the oracle; candidates contain only ID and composition. Python does not provide an adversarial isolation sandbox, but typed/immutable interfaces, module boundaries and target-invariance tests guard accidental leakage. Global audit class counts determine only the conservative calibration gate; hidden individual labels never affect modeling or acquisition.

Secondary outcomes: best feasible hardness at 5/10/15, failed rank-screen count/rate, first feasible query (0 if already present, censored if absent at 15), probability any feasible by budget, prequential Brier/log loss, regression MAE/NLL/coverage, ranking changes, fallback/warning/activation rates, timing. Different policies' selected forecasts are different adaptive populations; scoring differences are not common-test-set predictive comparisons. Paired t intervals across seed-level differences condition on one finite pool and do not imply independent physical replications.

One-seed (314) and five-seed smoke (0–4) verified execution before final freeze. Final comparison used frozen seeds 0–29 and no policy adjustment. Exploratory initialization sensitivities use n=8 and n=16 with seeds 100–104 and 15 selections each. They cannot prove an optimal initialization, since total measurement costs differ. Chemistry groups use KMeans on compositions alone, k=3, seed 0, n_init=10. Requiring >=15 target groups and >=4 positives on each side yields insufficient support. No OOD outcome comparison is reported.

The report is a test of a prespecified decision procedure on already measured candidates. It contains no newly synthesized material, paired simulation discrepancy model, proprietary-system comparison or theoretical reliability guarantee.
